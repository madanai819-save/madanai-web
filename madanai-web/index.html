PHILOSOPHY

私たちの理念

「まだない」を「もうある」へ

まだ形になっていない想い、言葉になっていない課題、始めたいのに進められていない挑戦。私たちは、それらを一つずつ整理し、動き出せる形へ変えていきます。

MISSION

挑戦を、動き出せる形にする。

やりたいことがあっても、方法が分からなかったり、時間や知識が足りず止まってしまうことがあります。私たちの使命は、その想いと課題を整理し、次の一歩を踏み出せる形に変えることです。

VISION

小さな会社の挑戦が、止まらない社会へ。

規模や専門知識に関係なく、必要な技術や仕組みを活用できる。新しいことを始めたい会社が、迷い続けずに前へ進める。そんな環境が当たり前になる未来を目指します。

VALUE

迷ったときに立ち返る、3つの判断基準です。

  • ・
    本質から考える

    流行や手段から考えるのではなく、まず何を変えたいのか、何が必要なのかを整理します。

  • ・

  • ・

    完成そのものではなく、使われ、改善され、前へ進む状態を大切にします。
